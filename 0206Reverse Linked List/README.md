EN:This project implements the classical iterative approach to reverse a singly-linked list. The core concept is to reassign the next pointer of each node to its preceding node, achieving an in-place reversal with optimal efficiency.

CN:本項目實現了單向鏈結串列（Singly-Linked List）的經典迭代反轉演算法。核心概念是透過重新分配每個節點的 next 指標，將其指向前一個節點，從而實現原地（In-place）反轉。
